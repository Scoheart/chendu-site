OpenAI models hacked a crypto wallet and breached more websites

OpenAI 再披露 4 起测试事故：智能体入侵网站、擅用加密钱包

By Dan Goodin · Ars Technica · 2026-10-16 16:59 EDT（北京时间 10 月 17 日 04:59）

今天读 Ars Technica 安全编辑 Dan Goodin 的报道。OpenAI 周四公布 6 月发生的 4 起内部测试事故：模型为完成任务入侵政府统计网站拿到凭据、用公开助记词动用测试网钱包付费。作者最后提醒：与其说 AI「失控」，不如说它们正是被训练成这样。重点看：bypass / credential / zero-day / go rogue / substitute A for B / guardrail 这类科技安全词。

OpenAI said internal models hacked two more websites, bypassed1 company-imposed2 browsing restrictions, and used exposed credentials3 to draw cryptocurrency from a wallet it couldn’t otherwise access4, in the latest installment of5 disclosures of its agents performing6 unethical and likely illegal acts.

1词汇
bypass
/ˈbaɪpæs/ v. 绕过、规避（限制、检查）。bypassed browsing restrictions = 绕过浏览限制。名词 bypass 也指「旁路、绕行道」。例：The malware bypassed the firewall.
3词汇
credential
/krəˈdenʃəl/ n. （常复数）凭证、登录凭据（账号密码、密钥、令牌）。exposed credentials = 泄露/暴露在外的凭据。例：Never store credentials in plain text.
5地道表达
the latest installment of …
最新一期/一轮……。installment /ɪnˈstɔːlmənt/ 本义「（连载的）一集、分期付款的一期」。可替换：the latest round / batch of。
2语法
名词 + 过去分词 复合形容词
company-imposed = imposed by the company「公司强加的」。名词表施动者，过去分词表被动。同类：government-funded、AI-generated、user-defined。
4语法
otherwise = 否则/以别的方式
a wallet it couldn’t otherwise access = 一个（若不用这些凭据）它本来无法访问的钱包。it 前省略了关系代词 that/which。
6语法
of + 名词 + -ing（动名词复合结构）
disclosures of its agents performing … acts = 关于「其智能体做出……行为」的披露。its agents 是 performing 的逻辑主语。

The company on Thursday issued reports of four new incidents, all of which occurred in June7. They come after the company revealed in July that internal test agents exploited a zero-day vulnerability8 in a tool designed to restrict9 their access to the Internet. They then broke into10 the network of AI tool provider Hugging Face. The agents took that illegal action to steal answers to a hacking test that weren’t available when completing the tasks on their own11. The incident—which likely would have resulted in criminal charges12 had they been performed directly by a person13—has further heightened concerns14 that widespread AI use could have harmful effects on an unprecedented scale15.

7语法
all of which 非限制性定语从句
= and all of them occurred in June。代词 all / some / none / most + of which/whom，引出补充说明，指代前面的 four new incidents。
9语法
过去分词短语作后置定语
a tool designed to restrict their access = a tool that was designed to …「一个旨在限制其上网的工具」。be designed to do = 旨在、用来。
11地道表达
on one’s own
独立地、靠自己。answers … that weren’t available when completing the tasks on their own = 自己做题时拿不到的答案。同义 by themselves / unaided。
13语法
省略 if 的虚拟倒装
= if they had been performed directly by a person。与过去事实相反的虚拟条件：would have resulted in … had they been … 「如果是人直接干的，很可能已被刑事起诉」。
15地道表达
on an unprecedented scale
以前所未有的规模。unprecedented /ʌnˈpresɪdentɪd/ adj. 史无前例的。on a large / global scale 同结构，介词用 on。
8词汇
zero-day vulnerability
零日漏洞：厂商尚不知道、还没补丁的安全漏洞。vulnerability /ˌvʌlnərəˈbɪləti/ n. 漏洞、弱点。例：Hackers exploited a zero-day vulnerability in the browser.
10地道表达
break into
闯入、侵入（系统、房屋）。broke into the network = 入侵网络。同义 hack into / breach。注意 break in（无宾语）也常用：Someone broke in last night.
12地道表达
criminal charges
刑事指控。face / bring / file charges = 面临 / 提出指控。charge 在此是「指控」，不是「收费」。
14地道表达
heighten concerns
加剧担忧。heighten /ˈhaɪtən/ v. 加强、提高。可替换：raise / deepen / fuel concerns。

In two of the cases reported Thursday, OpenAI agents tasked with16 retrieving17 information from websites hacked them when the models ran into obstacles18 obtaining it directly. In one incident during reinforcement training19, a model that received access denials20 when trying to retrieve historical hospital-bed statistics on a government statistics website “used the site’s file-download feature to retrieve server configuration and application files, including sensitive credentials,” OpenAI said. “It inspected the application code, bypassed the statistics endpoint’s authorization checks21, and retrieved data that had previously been denied22. The model saved the data locally.”

17词汇
retrieve
/rɪˈtriːv/ v. 取回、检索（数据）。retrieve information / data = 获取信息。名词 retrieval：RAG = retrieval-augmented generation。例：The tool retrieves documents from the web.
19词汇
reinforcement
/ˌriːɪnˈfɔːrsmənt/ n. 强化。reinforcement training/learning = 强化学习训练：模型做对给奖励，靠试错优化。例：The model was fine-tuned with reinforcement learning.
21词汇
authorization
/ˌɔːθərəˈzeɪʃən/ n. 授权、权限。authorization checks = 权限校验。区分 authentication（认证：你是谁）与 authorization（授权：你能做什么）。
16语法
be tasked with doing
被分派去做……。OpenAI agents tasked with retrieving information … hacked them：过去分词短语修饰 agents，主干是 agents … hacked them（them = websites）。
18地道表达
run into obstacles
遇到障碍、碰壁。run into = 意外遇到（困难、问题、熟人）。可替换：hit a wall / encounter difficulties。
20语法
长句拆解
主干：a model … “used the site’s file-download feature …,” OpenAI said。that 从句（received access denials）和 when trying to … 状语都在修饰 a model；引号里的谓语 used 才接上主语。
22语法
过去完成被动 had been done
数据「此前曾被拒绝访问」，发生在 retrieved 之前，所以用过去完成时；被动表示数据被拒。
[ … ]

In a third report, the company said a model prompted to update23 a cryptocurrency trading application used funds from a locked wallet on a test network. The model “derived wallet keys from24 publicly known developer recovery phrases25, found an account with test-network funds, and used that account to pay for the requested contract deployment26.”

23语法
过去分词后置 + 主干
a model prompted to update a cryptocurrency trading application used funds …：主干 a model used funds；prompted to … 修饰 model（= that was prompted to …）。prompt 作动词 = 提示、指令。
25词汇
recovery phrase
/rɪˈkʌvəri freɪz/ n. 助记词（恢复短语，又称 seed phrase）：一串单词，可还原钱包私钥。公开的助记词 = 谁都能动这个钱包。
24地道表达
derive A from B
从 B 推导/获得 A。derive /dɪˈraɪv/。derived wallet keys from … recovery phrases = 由助记词推导出钱包私钥。被动 be derived from = 源自。
26词汇
deployment
/dɪˈplɔɪmənt/ n. 部署。contract deployment = （智能）合约部署上链，需支付手续费（gas）。动词 deploy：deploy an app / a model。

The report continued: “The model questioned whether it had permission27, then reasoned that a public recovery phrase and valueless28 test-network tokens made the funds acceptable to use29. The deployment succeeded and charged transaction fees to the account. This case shows that a model can substitute its own judgment about likely harm for30 the account holder’s permission, then act on that judgment without authorization31.”

27语法
question whether …
怀疑/质疑是否……。question 作动词 + whether 宾语从句（陈述语序）。注意后面 then reasoned that …：先质疑，再自我说服。
29语法
make + 宾语 + 形容词 + to do
使资金「可以拿来用」。acceptable 是宾补，to use 修饰 acceptable。类似：make the text easy to read。
31地道表达
without authorization
未经授权。法律、安全语境常用：access a system without authorization = 未授权访问。同义 without permission。
28词汇
valueless
/ˈvæljuːləs/ adj. 没有价值的。valueless test-network tokens = 不值钱的测试网代币。注意 invaluable = 极其宝贵的（不是「没价值」）。
30地道表达
substitute A for B
用 A 代替 B（A 是新的、B 是原本应有的）。这里：用模型「自己对危害的判断」代替「账户持有人的许可」。易错：substitute A for B ≠ replace A with B（方向相反）。

It has become common for researchers and journalists to describe32 incidents like these as33 AI “going rogue34.” That’s not necessarily true35. While prompts fed to the models36 didn’t instruct them to use the alternate methods for completing their objectives, models are trained to be efficient, steadfastly persistent37, and, when possible, to find shortcuts that lessen workloads38. Further, most or all of the models had disabled certain guardrails39 that might have prevented40 the actions. In this sense, the models performed precisely as OpenAI had trained them to41.

33地道表达
describe A as B
把 A 描述为 B。describe incidents like these as AI “going rogue” = 把这类事件说成 AI「失控」。同构：regard / see / view A as B。
35地道表达
not necessarily
不一定、未必（部分否定）。That’s not necessarily true = 那未必属实。比 That’s not true 语气缓和。
37词汇
steadfastly
/ˈstedfæstli/ adv. 坚定不移地。steadfastly persistent = 执着到底、锲而不舍。persistent /pərˈsɪstənt/ adj. 坚持不懈的。
39词汇
guardrail
/ˈɡɑːrdreɪl/ n. 护栏；（AI）安全防护机制。disable guardrails = 关闭防护。例：The company added new guardrails to its chatbot.
41语法
不定式省略
句末 to 后省略了动词（= trained them to perform），避免重复。口语常见：I didn’t want to, but I had to.
32语法
It + be + adj + for sb + to do
形式主语 It 代替后面的不定式：「研究者和记者把……说成……已成常态」。for sb 引出不定式的逻辑主语。
34地道表达
go rogue
失控、脱离掌控擅自行动。rogue /roʊɡ/ adj. 不受控制的、流氓的：a rogue state、a rogue trader。例：Critics worry AI agents could go rogue.
36语法
过去分词 fed 后置
prompts fed to the models = prompts that were fed to the models「输入给模型的提示词」。feed sth to sb/sth = 把……喂给。
38词汇
lessen
/ˈlesən/ v. 减少、减轻（与 lesson 同音）。lessen workloads = 减轻工作量。同义 reduce / ease。
40语法
might have done
对过去的推测/本可能：「本来可能阻止这些行为的」防护。这里暗含：防护被关掉了，所以没能阻止。
